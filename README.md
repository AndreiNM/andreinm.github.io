# 🛡️ PortSwigger Web Security Labs

Welcome!

This repository contains my solutions and notes from the **PortSwigger Web Security Academy**.

I believe **hands-on practice is the best way to learn cybersecurity**, so instead of only studying theory, I solve real-world labs using tools like **Burp Suite** and document what I learn.

## 📂 Topics
- Authentication
- Access Control
- SQL Injection
- XSS
- CSRF
- SSRF
- File Uploads
- XXE
- Business Logic
- Information Disclosure

Each write-up includes:
- Vulnerability overview
- Exploitation steps
- Burp Suite examples
- Key takeaways

**Learning by doing. One lab at a time.** 🚀
